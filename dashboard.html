Connect your analytics

Read directly from the GoatCounter API in your browser. Nothing is sent anywhere else — the token is stored only in this browser's localStorage.

  1. Create a free account at goatcounter.com/signup. The site code you choose becomes your subdomain — e.g. chujunzong → chujunzong.goatcounter.com.
  2. In GoatCounter click your username in the top menu → API, then Add token. Tick “Read statistics” (the only permission this dashboard needs). Copy the token — it is shown once.
  3. Paste both below and press Connect.
